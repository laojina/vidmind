# VidMind v1.0.0

日期：2026-10-14。

## 范围

- 已有 Java 视频 Agent 基线：RocketMQ 异步分析、ASR/OCR 时间轴、分段 RAG、LangChain4j ChatModel、Checkpoint 与 Vue 演示工作台。
- 统一源码和开发配置模板中的项目名称、临时文件前缀、事件频道和浏览器存储键。
- 修复证据来源标签校验与服务层登录密码长度边界，补充回归测试。
- README 以 Java 后端为主，补充职责、架构与限制；新增工程风险和源码面试问答。
- 规范既有提交说明，保留原始作者、日期和代码快照；新提交记录本次实际工作，未模拟跨天开发。
- 后端 Maven 版本为 1.0.0，Git annotated tag 为 v1.0.0；前端演示包保持独立版本。

## 验证

本机 Java 23 以 Java 21 目标编译，7 个后端测试通过；前端 2 个测试与生产构建通过。新版 JDK 上测试使用显式 Mockito agent，Lombok 使用 full annotation processing。Compose 配置校验由 CI 执行，本机没有 Docker CLI，未宣称中间件启动验收。

## 升级

持久化数据库账号不会随配置模板自动重建。现有本地账号与密钥保持原值，迁移需单独创建/授权新账号。所有后端实例统一重启以切换事件频道；前端本地模式与目标偏好需重新设置。

## 已知限制

仍有上传跨系统幂等窗口、外链 SSRF 网络边界、MQ 投递一致性、锁竞争结果传播、向量模型迁移、孤儿分片和连接配额问题。完整说明见 [工程风险](../engineering-risks.md)。v1.0.0 标记源码快照，不代表生产 SLA 或所有 bug 已排除。
